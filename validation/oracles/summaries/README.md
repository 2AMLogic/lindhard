# Oracle comparison summaries

One JSON file per (oracle, problem), written by `../run.py` and committed by
hand after review. Format `lindhard-oracle-summary/1`: the problem id, the
oracle's name, version and licence note, our `lindhard` version, our own
metric values, and the `comparison` (relative differences, an absolute
backscatter difference, a speed ratio). Never the oracle's raw tables or
curves (`CONTRIBUTING.md`, Oracles).

None yet: the oracle adapters are tracked by #50.
