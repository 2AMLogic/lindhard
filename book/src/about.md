# About and the clean-room rule

lindhard is a Monte Carlo engine for the transport of ions and electrons in
matter. Every model comes from published papers and cites its source where it
is implemented. The code is clean-room: nothing is ported from code whose
license does not allow it, and no tabulated output of other programs is used
as data. What may be ported, what may only be read about in papers, and what
may never enter the tree are set out as license tiers in
[`CONTRIBUTING.md`](https://github.com/2AMLogic/lindhard/blob/main/CONTRIBUTING.md),
together with the disclosure rules.

lindhard is released under the MIT license
([`LICENSE`](https://github.com/2AMLogic/lindhard/blob/main/LICENSE)). The
source is at <https://github.com/2AMLogic/lindhard>.
