# Output files

`lindhard run input.toml --out dir/` writes `summary.json` and up to five
CSV profiles into `dir/`. The [first run](first-run.md) shows excerpts of
each from a real run. The models behind the damage figures are on
[Displacement damage](../models/damage.md).

This page is the output section of
[`docs/cli.md`](https://github.com/2AMLogic/lindhard/blob/main/docs/cli.md),
included here so there is one copy.
