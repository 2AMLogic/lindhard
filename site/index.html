lindhard

Ranges, damage, sputtering and backscattering for ions entering layered amorphous targets, computed by Monte Carlo in the binary-collision approximation.

What it computes

  • Ranges. Where ions stop in a layered target, with the projected range and its straggle.
  • Damage. Displacement damage from the collision cascades.
  • Sputtering and backscattering. What leaves the surface, and with what yield.
  • Reproducibly. A run gives the same bits on one thread or many.

A low-energy electron engine is under development. Every model is taken from published papers and cited where it is implemented. The code is clean-room: the license tiers say what may be ported and what may only be read about.

Build from source

There is no published release yet, so there is no package to install; build it with a stable Rust toolchain. See Installing.

Build

git clone https://github.com/2AMLogic/lindhard.git
cd lindhard
cargo build --release -p lindhard-cli

Run

target/release/lindhard run examples/b_5keV_si.toml --out out/b_5keV_si

The first run walks through that example (5 keV boron into silicon) from start to finish.
