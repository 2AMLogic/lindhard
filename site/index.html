lindhard

A clean-room, MIT-licensed Rust engine for Monte Carlo transport of ions in matter.

  • Book

What it is

For a beam of ions entering a layered amorphous target, lindhard computes where the ions stop, how much damage their cascades make, and what is sputtered and backscattered. It works in the binary-collision approximation (BCA). Results are deterministic: a run gives the same bits on one thread or many.

An electron engine is planned and has not been started. lindhard is early, pre-release software.

Every model is taken from published papers and cited where it is implemented. The code is clean-room: the license tiers say what may be ported and what may only be read about.

Physics covered

One manual page per model, with the equations, the assumptions, the range of use and the papers.

  • Interatomic potentials and their screening lengths
  • The scattering integral
  • Electronic stopping (Lindhard–Scharff, Oen–Robinson, Bethe–Bloch, user tables, Bragg additivity) and straggling
  • BCA transport
  • Displacement damage
  • Dynamic composition

Install and quick start

lindhard is not yet published as a package; build it from source with a stable Rust toolchain. See Installing.

git clone https://github.com/2AMLogic/lindhard.git
cd lindhard
cargo build --release -p lindhard-cli
target/release/lindhard run examples/b_5keV_si.toml --out out/b_5keV_si

The first run walks through that example (5 keV boron into silicon) from start to finish.

Try it

  • Range calculator: projected range and straggle in your browser, as WebAssembly. Nothing you enter leaves your machine.

How far to trust it

Validation is reported in full, including where lindhard does not agree with a reference. Known gaps exist and are listed, with their causes, under Known deviations in the validation document; read them before relying on a result. The document also holds the analytic-check results, the code-to-code comparisons and the comparisons with measurement, and says where a comparison is missing. The data provenance table records where every number in the tree comes from.
