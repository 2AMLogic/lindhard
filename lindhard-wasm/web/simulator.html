lindhard simulator

Set up a beam and a layered amorphous target, then run it. The lindhard binary-collision engine runs in your browser (WebAssembly, in a Web Worker); nothing is sent to a server. The range calculator is the one-element shortcut.

Ion

Target layers (surface first)

Blank energy fields use the element table's value, shown as the placeholder; a field with no table value must be filled in. Preset densities cite the sources in the data provenance table. The Si and SiO₂ presets carry illustrative displacement energies (Si 15 eV, O 20 eV), model parameters rather than recommendations; the GaAs preset leaves Ga and As blank, so enter them.

Physics

The recoil cutoff must stay below the smallest surface binding energy, or sputtered atoms are lost.
